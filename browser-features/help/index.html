derp help

Documentation for the features derp adds on top of Firefox.

Topics

  • Workspaces — Separate sets of tabs you switch between from the chooser at the far left of the tab strip.
  • Tab stacks — Vivaldi-style two-level tabs.
  • Zen mode — Retracts the toolbars and the status bar so only the page is left.
  • Panel sidebar — A sidebar for web panels, notes and extensions, kept beside the page rather than over it.
  • Split view — Two or more pages side by side inside a single tab.
  • Mouse gestures — Hold the right mouse button and draw to run a command.
  • Importing from another browser — Brings passwords, bookmarks, history and cookies across from Vivaldi, Chrome, Edge or Safari.
  • Web apps — Installs a site as a standalone desktop application.
  • Keyboard shortcuts — The shortcuts derp adds on top of Firefox's, and how to change them.
  • Extensions and Manifest V2 — derp runs Manifest V2 extensions, so the full uBlock Origin works rather than the reduced Lite version.
