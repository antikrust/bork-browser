Delete comments

Your YouTube comments, replies and live chat messages, in bulk.

What

Which

Leave everything empty to take all of them. One rule per line; plain text matches anywhere, ignoring case, and /pattern/flags is a regular expression. Lines starting with # are ignored.

Go

This works through Google's My Activity, which opens in a window of its own — the list only loads while it is on screen, so leave it there until this finishes. Find goes through everything and deletes nothing; Delete cannot be undone. Google says a deleted comment can take a few hours to vanish from YouTube itself.
