derp browser

derp based on floorp

a compact fork of Floorp 12 (Firefox 152) — Vivaldi-style workspaces and tab stacks, zen mode, lean UI, no AI.

why this exists

Chrome's move to Manifest V3 deliberately broke full-strength content blocking. derp is built on Firefox, which still runs Manifest V2 extensions, so the complete uBlock Origin — not the declawed Lite version — keeps working exactly as it always did. No filter-list cap, no crippled request blocking.

Everything else follows from the same instinct: no AI assistant, no sponsored tiles, no telemetry, no engagement features nobody asked for.

coming from Vivaldi?

derp imports your Vivaldi workspaces, including which tabs live in which workspace — it reads Vivaldi's own session data, so a workspace with twenty tabs arrives as a workspace with twenty tabs. Passwords, bookmarks, history and cookies import too, from Vivaldi, Chrome, Edge or Safari.

getting around

derp is built to work with the chrome out of the way. These are the macOS keys:

  • ⌘⌥ + drag — move the window from anywhere on it, no title bar needed
  • ⌘⌥A — hide or show the address bar
  • ⌘⌥S — hide or show the panel sidebar
  • ⌘⌥Z — zen mode: toolbars and status bar retract, leaving the page
  • Double-click a tab — type a URL straight into it. With the address bar hidden this is how you navigate; Enter goes, Escape backs out. Tabs in a stack's second row do the same.
  • ⌘← and ⌘→ — back and forward (⌘[ and ⌘] also work)

The chrome controls sit on ⌘⌥ rather than bare keys so they cannot fire while you are typing into a page. On Windows and Linux the same controls are Ctrl+Alt — Ctrl+Alt+A, Ctrl+Alt+S, Ctrl+Alt+Z, and Ctrl+Alt+drag to move the window.

installing

  • macOS: open the DMG, drag Derp to Applications. These builds are self-signed — first launch is right-click → Open.
  • Linux: tar -xzf Derp-linux-x86_64.tar.gz && ./floorp/floorp
  • Windows: unzip anywhere, run floorp.exe. SmartScreen will grumble — More info → Run anyway.

notes

  • The engine binary keeps its upstream name (floorp) — derp is the feature layer on top.
  • Profiles live in the standard Floorp location, so derp and Floorp share profile storage — back up before switching between them.
  • Source, issues and the full story: github.com/100mountains/derp
