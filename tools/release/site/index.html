bork browser

bork based on floorp

a compact fork of Floorp 12 (Firefox 152)

NO AI (No ONNX runtime, no transformers.js, no wllama, no openai.mjs, no model hub, and both MLEngine actors removed. browser.ml.enable is set to false.)

No telemetry, no data sharing, no crash reports, fuck all that noise.

Does Workspaces, Tab Stacks, Tab Groups, Zen mode, split view, mouse gestures, side panels (notes, downloads, a local translator), a command palette on F2, an address bar that hides completely, and chromium plugins.

why this exists

Chrome's move to Manifest V3 deliberately broke full-strength content blocking. bork is built on Firefox, which still runs Manifest V2 extensions, so the complete uBlock Origin — not the declawed Lite version — keeps working exactly as it always did.

coming from Vivaldi?

bork imports your Vivaldi workspaces, including which tabs live in which workspace — it reads Vivaldi's own session data, so a workspace with twenty tabs arrives as a workspace with twenty tabs. Passwords, bookmarks, history and cookies import too, from Vivaldi, Chrome, Edge or Safari.

getting around

bork is built to work with the chrome out of the way. These are the macOS keys:

  • ⌘⌥ + drag — move the window from anywhere on it, no title bar needed
  • ⌘⌥A — hide or show the address bar
  • ⌘⌥S — hide or show the panel sidebar
  • ⌘⌥W — hide or show the workspaces rail
  • ⌘⌥Z — zen mode: toolbars and status bar retract, leaving the page
  • Double-click a tab — type a URL straight into it. With the address bar hidden this is how you navigate; Enter goes, Escape backs out. Tabs in a stack's second row do the same.
  • ⌘← and ⌘→ — back and forward (⌘[ and ⌘] also work)

The chrome controls sit on ⌘⌥ rather than bare keys so they cannot fire while you are typing into a page. On Windows and Linux the same controls are Ctrl+Alt — Ctrl+Alt+A, Ctrl+Alt+S, Ctrl+Alt+W, Ctrl+Alt+Z, and Ctrl+Alt+drag to move the window.

installing

  • macOS: open the DMG, drag Bork to Applications. These builds are self-signed — first launch is right-click → Open.
  • Linux: tar -xzf Bork-linux-x86_64.tar.gz && ./floorp/floorp
  • Windows: unzip anywhere, run floorp.exe. SmartScreen will grumble — More info → Run anyway.
