installing

  • macOS: open the DMG, drag Derp to Applications. These builds are self-signed — first launch is right-click → Open.
  • Linux: tar -xzf Derp-linux-x86_64.tar.gz && ./floorp/floorp
  • Windows: unzip anywhere, run floorp.exe. SmartScreen will grumble — More info → Run anyway.

notes

  • The engine binary keeps its upstream name (floorp) — derp is the feature layer on top.
  • Profiles live in the standard Floorp location, so derp and Floorp share profile storage — back up before switching between them.
  • Source, issues and the full story: github.com/100mountains/derp
